LIVE PROJECTIONS

Dalton says: race over

Live call trigger: when a snapshot arrives, Dalton projects only if a documented JSON feed marks the contest final and non-stale, every named candidate has a valid total, there is one vote leader, and any source-declared winner agrees with that leader. This live rule has no statistical probability threshold; county subtotals and unverified state-page rows cannot trigger calls. Demo calls use a separate illustrative 99.5% model after the race's polls close. Projections are not official certifications.
